# Before launch

- Set up a new [Paddle](https://www.paddle.com/) account, products, prices, client token, API key, and webhook for the production domain.
- Provision a new Postgres database, apply the included schema and migrations, and configure Resend for transactional email.
- Replace placeholder copy, artwork, coach details, testimonials, Discord links, and WhatsApp links with approved final content.
- Update the production domain in `index.html`, `public/sitemap.xml`, `public/robots.txt`, and `PUBLIC_BASE_URL`.
- Confirm the legal terms and permission to use all photos, game artwork, fonts, and partner branding, then test checkout, email, talent access, and mobile layouts before launch.
